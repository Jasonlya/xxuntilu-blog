我是一名测试开发工程师，长期关注自动化测试、质量工程、CI/CD 和 AI Agent 评测相关内容。

这个博客主要记录我在工程实践中的思考，内容会覆盖：

- 自动化测试框架搭建
- API / UI / E2E 测试实践
- 测试开发工程能力提升
- CI/CD 中的质量门禁设计
- Agent / LLM 的评测方法
- 软件可靠性和工程效率的平衡

我相信，测试工程的价值不只是“发现问题”，更重要的是把质量建设成为工程能力，让团队能够持续、稳定地交付可信软件。

这是我个人技术博客的记录，用来沉淀实践、分享经验、复盘方法，也希望能和同行一起交流。

## 关注方向

- 自动化测试
- 测试开发
- 质量工程
- Agent / LLM 评测
- CI/CD
- 测试基础设施

## 工作方式

我喜欢把问题拆成工程问题，而不是单纯的“脚本问题”。因此，很多内容会围绕：

- 如何设计一个稳定可维护的测试框架
- 如何把自动化测试接入开发流程
- 如何让测试真正成为质量反馈
- 如何在 AI 时代重新理解测试和评测
